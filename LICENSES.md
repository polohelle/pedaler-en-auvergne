# Licences

Le dépôt mélange du code, des textes rédigés et une base de données d'acteurs
dont une partie provient d'OpenStreetMap. Chaque famille a sa licence.

| Quoi | Où | Licence |
| --- | --- | --- |
| Code source, configuration, scripts, outillage | tout le dépôt, sauf mentions ci-dessous | [MIT](LICENSE) |
| Textes rédigés : articles et brèves, descriptions des événements, descriptions des acteurs | `src/content/actus/`, `src/content/evenements/`, corps Markdown des fiches de `src/content/acteurs/` | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.fr) |
| Base de données de l'annuaire : champs structurés des fiches acteurs (nom, adresse, coordonnées, horaires, services…) | frontmatter des fiches de `src/content/acteurs/` | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |

## Données OpenStreetMap

Une partie de l'annuaire est issue d'OpenStreetMap (fiches portant `source: osm`).
Ces données sont © contributeurs OpenStreetMap, sous licence ODbL 1.0
(<https://www.openstreetmap.org/copyright>). Toute réutilisation de l'annuaire doit :

- mentionner « © contributeurs OpenStreetMap » et « Pédaler en Auvergne » ;
- redistribuer les versions modifiées de la base sous ODbL (partage à l'identique).

L'ODbL distingue la base de données de son contenu : les descriptions rédigées
des fiches sont un contenu, publié sous CC BY-SA 4.0.

## Marque

Le nom « Pédaler en Auvergne », ses déclinaisons « Pédaler à… » et le logo
ne sont couverts par aucune de ces licences. Leur usage demande l'accord de
l'association.

## Contenus de tiers

Les actualités et événements repris de la veille renvoient à leur source
d'origine (`source_url`) : seul le résumé rédigé est sous CC BY-SA 4.0, jamais
le contenu de la source. Les images fournies par les acteurs restent sous
leurs conditions propres, indiquées dans le crédit.
